# cc-25832071003-SkripsiTrack

SkripsiTrack adalah proyek perencanaan dan pengembangan website manajemen skripsi berbasis Cloud Computing.

## Infrastruktur
- Provider: IDCloudHost
- VPS: gania-svr
- OS: Ubuntu Server 24.04 LTS
- Spesifikasi: 2 vCPU, 2 GB RAM, 20 GB disk

## Praktikum M03
- Akses VPS menggunakan PuTTY (SSH)
- Konfigurasi firewall UFW
- Konfigurasi swap 1 GB
- Instalasi Flask dan Gunicorn
- Deployment aplikasi: dalam proses verifikasi
